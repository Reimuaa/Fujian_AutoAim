# XUC V2 Phase 2B：yaw 视觉跟随

Phase 2B 用于在 Phase 2A 已完成真实电机动作验证后，让 yaw 云台在受限范围内持续跟随装甲板。

## 行为

- 保持 V2 协议：上位机下发 14 字节，下位机反馈 20 字节，USART6 460800。
- 保持 DR16 左中、右下的显式解锁边沿；上电时已经处于该档位不会自动解锁。
- yaw 目标限制在解锁位置的正负 25 度内，目标变化速度限制为每秒 15 度。
- `control` 短暂丢失不超过 200 ms 时保持最后目标，减少视觉漏检导致的反复撤控，同时限制旧目标导致的过冲。
- `control` 连续丢失超过 200 ms，或遥控器、严格 CRC IMU、XUC 命令任一超时，立即撤控并要求重新拨动开关解锁。
- pitch 不接入自动控制；shoot 始终关闭；AUTO 时底盘停止。
- 沿用 Phase 2A 实车确认能克服静摩擦的 yaw 电机参数，不再提高输出上限。

## 首次实车测试

1. 架空底盘，清空云台左右各 30 度范围内的人员、线缆和障碍物，关闭摩擦轮并卸弹。
2. 遥控器先置安全档，启动上位机程序，确认红色装甲板持续被识别且 XUC 反馈有效。
3. 将装甲板放在画面中央，再拨到左中、右下解锁。
4. 缓慢把装甲板移到画面左侧和右侧；云台应朝缩小画面水平误差的方向转动。
5. 若云台朝反方向运动，立即拨回安全档并停止上位机程序，不要靠继续运行验证。
6. 遮挡装甲板少于 200 ms 时云台应保持最后目标，恢复识别后继续跟随；长时间遮挡应撤控。
7. 拔掉串口或关闭上位机后，云台必须停止；恢复后必须重新拨动开关才能解锁。

Phase 2B 仍是 yaw 台架功能，不包含 pitch 跟随和射击授权。
