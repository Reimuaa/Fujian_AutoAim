# XUC V2 Phase 2A：受限 yaw 接板测试

Phase 2A 只用于第一次云台闭环动作验证。它不是最终自瞄控制参数。

## 固定边界

- 小电脑链路：USART6，PC6(TX)/PC7(RX)，460800，8N1；
- 只接入 `yaw_TJ`，`pitch_TJ` 完全忽略；
- `shoot_TJ` 完全忽略，XUC 不连接发射状态机；
- 遥控器必须在线；
- IMU 必须在最近 100 ms 内有严格 CRC 通过的解析结果；仅靠历史累计次数或
  CRC 失败后的兼容解析不能解锁；
- XUC 命令必须在 200 ms 内收到且 `control_TJ=1`；
- 四个摇杆必须处于中位附近；
- 必须先把拨杆移出自动档，再明确切入左 MID、右 DOWN；
- 任何门条件失效都立即撤销 AUTO，并要求重新拨动一次才能恢复；
- yaw 总目标始终限制在解锁瞬间的 ±1°；
- 目标变化率不超过 5°/s；
- 下位机反馈 `mode_TJ=1` 表示这些门条件全部成立，否则为 0。

## 烧录后的安全顺序

1. 无弹、摩擦轮断能、机器人架稳，人员离开 yaw 扫掠范围。
2. 遥控器保持非自动档，先运行小电脑 `xuc_board_probe` 只接收测试。
3. 运行 `--safe-heartbeat`；其 `control=0`，云台不得动作。
4. 小电脑完整自瞄配置仍保持 `xuc_allow_control: false`，验证相机和反馈。
5. 另复制一份 Phase 2A 专用配置，只把 `xuc_allow_control` 改为 `true`，且保持
   `xuc_allow_shoot: false`。
6. 装甲板置于画面中央并启动上位机。确认持续识别后，先把拨杆移出自动档，
   再切到左 MID、右 DOWN。
7. 首次动作不应超过解锁位置 ±1°。切离该档、遮挡目标、拔掉 XUC 串口或让
   遥控器离线，都必须撤控；恢复后不能自动重启，必须重新拨动。

## 停止条件

出现以下任一情况立刻切离自动档并关闭电源：

- 动作方向与目标相反；
- 运动超过约 1°；
- 串口断开后仍继续移动；
- 遥控器切离自动档后仍继续移动；
- pitch、摩擦轮或拨弹轮出现任何动作；
- 异响、抖振、发热或机械干涉。

Phase 2A 验收通过后，才能在独立提交中逐级扩大 yaw 范围和速度；pitch 与射击
必须继续作为不同阶段处理。

## 2026-09-03 现场 CRC 修正

HiPNUC/CH010 二进制帧的 CRC-16/XMODEM 初值为 `0x0000`，校验范围是
`5A A5`、两字节长度和整个数据域，不包含位于偏移 4、5 的 CRC 字段。不能只对
数据域计算 CRC。

现场以 2 MHz SWD 原子化读取了三份 82 字节帧，帧内 CRC 与正确算法分别得到的
`0x9D02`、`0x0A62`、`0x2DA7` 全部一致。旧实现漏算前四字节，因此所有合法
CH010 帧都只能进入兼容解析，`last_strict_decode_ms` 始终为零，Phase 2A 必然
拒绝解锁。兼容解析得到的非零姿态只能用于诊断，不能作为闭环控制依据。

修正后必须从空构建目录重新编译 Release，不能复用修正前的对象文件。烧录后先
确认严格 CRC 计数持续更新，再重新执行本文的拨杆边沿和 ±1° 受限 yaw 测试。
