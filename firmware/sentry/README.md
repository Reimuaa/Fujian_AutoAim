# RoboMaster Sentry Robot Control System (Sentry RCS)

这是一个基于 **STM32F405** 微控制器和 **FreeRTOS** 实时操作系统的 RoboMaster 哨兵机器人嵌入式控制软件。本项目集成了底盘运动控制、云台姿态解算、自动瞄准与导航（NUC通信）、裁判系统交互以及功率管理等核心功能。

## 📌 项目简介

该代码库旨在为哨兵机器人提供稳定、高效的控制逻辑。系统采用多任务架构，结合了多种控制算法（PID、滑模控制、卡尔曼滤波）和高级功能（RLS功率限制、自定义裁判系统UI），以适应 RoboMaster 比赛的复杂对抗环境。

* **开发环境**: Visual Studio + VisualGDB
* **硬件平台**: STM32F405RG
* **底层框架**: STM32 HAL库 + FreeRTOS

## ✨ 主要功能

### 1. 运动控制
* **全向底盘控制**: 支持麦克纳姆轮底盘运动学解算，具备小陀螺（自旋）模式、跟随模式、独立模式及导航模式。
* **云台控制**: 
    * 支持 **DM (达妙)** 直驱电机控制 Yaw/Pitch 轴。
    * 集成 **滑模控制 (SMC)** 算法，提高云台响应速度与抗干扰能力。
    * 包含角度解算与防缠绕/限位逻辑。
* **发射机构**: 支持摩擦轮与拨弹轮控制，具备卡弹检测与反转逻辑。

### 2. 算法与优化
* **功率限制**: 基于 **RLS (递归最小二乘法)** 的自适应功率预测与限制算法，在保证底盘性能的同时防止超功率。
* **滤波算法**: 
    * **卡尔曼滤波 (Kalman Filter)**: 用于传感器数据融合与平滑。
    * **低通滤波**: 抑制高频噪声。
* **姿态解算**: 支持多种 IMU (HI226, CH010, IMU601) 数据解析与欧拉角计算。

### 3. 系统交互
* **上位机通信**: 与 NUC (Mini PC) 通过串口通信，接收自动瞄准 (Auto-aim) 和导航 (Navi) 指令，发送机器人状态。
* **裁判系统**: 完整解析裁判系统数据，并实现了自定义 **客户端 UI 绘制** (绘制电容电压、模式状态、辅助线等)。
* **超级电容**: 通讯与控制逻辑，支持充放电管理。

## 🛠️ 硬件依赖

* **MCU**: STM32F405RG
* **电机**:
    * 底盘: DJI M3508
    * 供弹: DJI M2006
    * 云台: DM-J 系列直驱电机 / DJI M6020
* **传感器**:
    * IMU: HI226 / CH010 / 陀螺仪模块
    * 功率计模块
* **通信接口**:
    * CAN总线: 电机通讯
    * UART/DMA: 遥控器 (DR16), 裁判系统, NUC, IMU

## 📂 文件结构概览

核心代码位于 `STM32F405/` 目录下：

* **任务调度 (`taskslist.cpp/h`)**: FreeRTOS 任务定义（电机更新、CAN发送、控制循环、数据解码）。
* **控制算法**:
    * `control.cpp/h`: 机器人整体状态机与控制逻辑核心。
    * `pid.h`: PID 控制器实现。
    * `slidingmodec.cpp/h`: 滑模控制算法实现。
    * `PowerLimiter.cpp/h`: 功率限制器（含 RLS 算法）。
    * `kalman.h`: 卡尔曼滤波器。
* **硬件驱动**:
    * `motor.cpp/h`: DJI 电机封装与闭环控制。
    * `DMmotor.cpp/h`: 达妙电机专用驱动。
    * `can.cpp/h`: CAN 总线收发配置。
    * `usart.cpp/h`: 串口与 DMA 配置。
    * `imu.cpp/h`: 多种型号 IMU 数据解码。
* **外设交互**:
    * `judgement.cpp/h`: 裁判系统协议解析与 UI 绘制。
    * `nuc.cpp/h`: 上位机通讯协议。
    * `RC.cpp/h`: 遥控器数据处理。
    * `supercap.cpp/h`: 超级电容通信。

## 🚀 快速上手

1.  **环境配置**: 确保已安装 Visual Studio 和 VisualGDB 插件，且已配置好对应的 ARM 工具链。
2.  **编译**: 打开 `FreeRTOS.sln`，选择 `Debug` 或 `Release` 配置进行编译。
3.  **下载**: 使用 ST-Link 或 J-Link 连接开发板，通过 VisualGDB 进行烧录。
4.  **调试**: 
    * 底盘电机 ID 配置：参考 `motor.h` 中的枚举定义。
    * 云台参数调整：在 `control.cpp` 中调整 PID 或 SMC 参数。

## ⚙️ 关键逻辑说明

### 自动扫描与自瞄
系统会在 `AUTO` 模式下接收 NUC 的目标角度。若未检测到目标，云台将根据 `AUTOMATION::autoScan` 逻辑进行自动扫描运动。

### 功率限制 (RLS)
`PowerLimiter` 类实时采集底盘电机电流与转速，利用递归最小二乘法在线估计系统参数（摩擦系数、电阻损耗等），预测当前功率并计算电流衰减系数，确保整车功率不超标。
