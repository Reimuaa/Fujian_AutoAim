# RM2026 哨兵机器人车辆情况概述

---

## 主控

- **MCU**：STM32F405，运行频率 168 MHz
- **操作系统**：FreeRTOS 实时操作系统
- **主要任务**：`CanTransmitTask`、`ArmTask`、`DecodeTask`、`MotorUpdateTask`、`ControlTask`

---

## 云台

云台分为大云台与小云台两级结构，小云台安装于大云台之上。

### 大云台（大 YAW 轴）

| 项目    | 详情                                          |
| ----- | ------------------------------------------- |
| 自由度   | 单轴：大 YAW                                    |
| 旋转范围  | **360° 连续旋转**，无限位                           |
| 用途    | 扩展小云台的可瞄准方位角范围                              |
| 驱动电机  | 达妙（DM）无刷电机 `DM_motorYaw`                    |
| 通信总线  | CAN2，电机 ID：`0x06`，启动帧 ID：`0x206`            |
| 控制方式  | 速度模式，外环位置 PID + 内环速度 PID（`DM_pid`：P=5, D=2） |
| 姿态传感器 | `imu_gimbal`，UART5，波特率 115200，CH010 协议      |

### 小云台（小 YAW 轴 + PITCH 轴）

小云台有两个轴，因车体结构（支撑柱遮挡）及线材长度限制，**两轴均设有机械/软件限位**，用于精准瞄准。

#### 小 YAW 轴

| 项目   | 详情                                                         |
| ---- | ---------------------------------------------------------- |
| 驱动电机 | M6020 直流无刷电机，CAN2，ID：`0x205 + 4 = ID5`                     |
| 控制方式 | 位置+速度双环 PID（外环：P=55, I=0.06, D=50；内环：P=1.38, I=0.06, D=30） |
| 旋转限位 | 软件限位，`maxangle = ±75°`                                     |

#### PITCH 轴

| 项目    | 详情                                                   |
| ----- | ---------------------------------------------------- |
| 驱动电机  | 达妙（DM）无刷电机 `DM_motorPitch`                           |
| 通信总线  | CAN1，电机 ID：`0x09`，启动帧 ID：`0x109`                     |
| 控制方式  | 位置模式，位置 PID（`DM_pid`：P=5, D=2）                       |
| 俯仰范围  | 约 **−65.9°（−1.15 rad）\~ 0°**，初始角度约 −42.4°（−0.74 rad） |
| 姿态传感器 | `imu_pantile`，UART1/USART1，波特率 115200，CH010 协议       |

## 底盘

| 项目    | 详情                                                        |
| ----- | --------------------------------------------------------- |
| 轮型    | 四个麦克纳姆轮（全向移动）                                             |
| 驱动电机  | 4× M3508，CAN2，ID1 \~ ID4                                  |
| 速度控制  | 速度环 PID（P=3.5, D=0.05），最大转速 5000 RPM                      |
| 运动自由度 | X 向平移、Y 向平移、Z 轴旋转（三自由度全向运动）                               |
| 运动模式  | `NORMAL`（跟随）、`ROTATION`（小陀螺）、`FOLLOW`（云台跟随）、`NAVI`（自主导航）等 |

### CAN1

| ID            | 设备             | 类型    | 控制模式    |
| ------------- | -------------- | ----- | ------- |
| `ID2` (0x202) | 摩擦轮 1          | M3508 | 速度环     |
| `ID3` (0x203) | 摩擦轮 2          | M3508 | 速度环     |
| `ID7` (0x207) | 拨弹电机           | M2006 | 速度环     |
| `0x09`        | 小云台 PITCH (DM) | DM 达妙 | 速度/位置模式 |

### CAN2

| ID              | 设备            | 类型    | 控制模式    |
| --------------- | ------------- | ----- | ------- |
| `ID1` (0x201)   | 底盘轮 1         | M3508 | 速度环     |
| `ID2` (0x202)   | 底盘轮 2         | M3508 | 速度环     |
| `ID3` (0x203)   | 底盘轮 3         | M3508 | 速度环     |
| `ID4` (0x204)   | 底盘轮 4         | M3508 | 速度环     |
| `ID5` (0x205+4) | 小云台小 YAW      | M6020 | 位置+速度双环 |
| `0x06`          | 大云台大 YAW (DM) | DM 达妙 | 速度/位置模式 |

## 控制模式

| 模式                     | 说明                         |
| ---------------------- | -------------------------- |
| `NORMAL`               | 遥控手动模式，云台跟随遥控输入            |
| `FOLLOW`               | 底盘跟随云台方向                   |
| `ROTATION`             | 底盘小陀螺旋转，云台保持方向             |
| `RESET`                | 云台归零复位                     |
| `AUTO` / `AUTOCONTROL` | 视觉自瞄自动模式，NUC 输出目标坐标控制云台    |
| `NAVI`                 | 自主导航模式，MID360 + NUC 联合控制底盘 |
| `SHOOT`                | 自动开火模式                     |
| `LOCK`                 | 锁定当前云台姿态                   |

### 自动瞄准状态机

```
IDLE → SEARCH → TRACK → LOCKED
```

| 状态       | 触发条件                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| `IDLE`   | 初始状态，无目标                                                                     |
| `SEARCH` | 未检测到目标，执行扫描（YAW 扫描速度 0.08 rad/帧，PITCH 扫描速度 0.003 rad/帧，扫描范围 ±0.3 rad ≈ ±17°） |
| `TRACK`  | 检测到目标，跟踪中                                                                    |
| `LOCKED` | 目标稳定 15 帧且偏差 < 0.02 rad（≈ 1°），进入锁定，可开火                                       |
| 丢失超时     | 连续 30 帧（约 0.3 s）无目标，退出 TRACK                                                 |
| 搜索超时     | 搜索持续超过 200 帧（约 2 s），停止扫描                                                     |

### 下位机通信包体（结构体/解码方式）

void NUC::Decode()
{
    pd_Rx = xQueueReceive((m_uart->UartQueueHandler), m_frame, NULL);
    if (m_frame[0] == 'S' && m_frame[1] == 'P')
    {
        /*if (verifyCRC16CheckSum(m_frame, 31))
        {*/
            xuc.mode_TJ         = m_frame[2];
            xuc.yaw_TJ          = u8_to_float(m_frame + 3);
            xuc.yaw_vel_TJ      = u8_to_float(m_frame + 7);
            xuc.yaw_acc_TJ      = u8_to_float(m_frame + 11);
            xuc.pitch_TJ        = u8_to_float(m_frame + 15);
            xuc.pitch_vel_TJ    = u8_to_float(m_frame + 19);
            xuc.pitch_acc_TJ    = u8_to_float(m_frame + 23);
            xuc.state_switch_TJ = (int8_t)m_frame[27]; // 姿态状态: 1=Move 2=Attack 3=Defense
            xuc.fire_control_TJ = (int8_t)m_frame[28]; // 火控许可: 0/1
            obs.target_yaw  = radianToDegree(xuc.yaw_TJ);
            obs.cur_yaw     = imu_gimbal.angle.yaw;
            obs.cur_pitch   = imu_gimbal.angle.pitch;
            if (xuc.mode_TJ)
            {
                obs.target_pitch     = radianToDegree(xuc.pitch_TJ);
                obs.target_pitch_pre = obs.target_pitch;
            }
            else
            {
                obs.target_pitch = obs.target_pitch_pre;
            }
        //}
    }
    else if (m_frame[0] == 'N' && m_frame[1] == 'A' && m_frame[2] == 'V' && m_frame[3] == 'I')
    {
        /*if (verifyCRC16CheckSum(frame, 20))
        { */
        xuc.RxNav.linear_x = u8_to_float(m_frame + 4);
        xuc.RxNav.linear_y = u8_to_float(m_frame + 8);
        xuc.RxNav.angular_z = u8_to_float(m_frame + 12);
        xuc.RxNav.isReached = m_frame[16];
        //}
    }

}



//同济大学（下位机和上位机）
void NUC::Encode()
{
    own_color = judgement.data.robot_status_t.robot_id <= 7 ? RED : BLUE;
    // 帧头
    TxNuc_TJ.head[0] = 'S';
    TxNuc_TJ.head[1] = 'P';
    TxNuc_TJ.mode_TJ = 1;  // 0: 空闲, 1: 自瞄, 2: 小符, 3: 大符
    // 云台姿态
    TxNuc_TJ.yaw_TJ       = imu_gimbal.angle.yaw;
    TxNuc_TJ.yaw_vel_TJ   = imu_gimbal.angularvelocity.yaw;
    TxNuc_TJ.pitch_TJ     = imu_gimbal.angle.pitch;
    TxNuc_TJ.pitch_vel_TJ = imu_gimbal.angularvelocity.pitch;
    TxNuc_TJ.roll_TJ      = imu_gimbal.angle.roll;
    TxNuc_TJ.roll_vel_TJ  = imu_gimbal.angularvelocity.roll;
    // 弹速与子弹数
    TxNuc_TJ.bullet_speed_TJ  = judgement.data.shoot_data_t.bullet_speed;
    TxNuc_TJ.bullet_count_TJ  = judgement.data.projectile_allowance_t.projectile_allowance_17mm;
    // 比赛状态（0=未开始 1=进行中 2=结束）
    TxNuc_TJ.game_status_NAV = (judgement.data.game_status_t.game_progress == 4) ? 1 :
                               (judgement.data.game_status_t.game_progress == 5) ? 2 : 0;

    // 底盘速度
    if (ctrl.chassis_motor[0] && ctrl.chassis_motor[1] &&
        ctrl.chassis_motor[2] && ctrl.chassis_motor[3])
    {
        const float k = ctrl.chassis_motor[0]->const_dx;  // RPM -> m/s
        float m0 = (float)ctrl.chassis_motor[0]->curspeed;
        float m1 = (float)ctrl.chassis_motor[1]->curspeed;
        float m2 = (float)ctrl.chassis_motor[2]->curspeed;
        float m3 = (float)ctrl.chassis_motor[3]->curspeed;
        TxNuc_TJ.chassis_vx = ( m0 + m1 + m2 + m3) * k / 4.0f;
        TxNuc_TJ.chassis_vy = (-m0 + m1 + m2 - m3) * k / 4.0f;
        TxNuc_TJ.chassis_wz = (-m0 + m1 - m2 + m3) * k / 4.0f;  // 角速度系数待校准
    }

    // 资源约束
    TxNuc_TJ.chassis_power_limit = (float)judgement.data.robot_status_t.chassis_power_limit;
    TxNuc_TJ.buffer_energy       = (float)judgement.data.power_heat_data_t.buffer_energy;
    TxNuc_TJ.shooter_heat        = (float)judgement.data.power_heat_data_t.shooter_17mm_1_barrel_heat;
    TxNuc_TJ.shooter_heat_limit  = (float)judgement.data.robot_status_t.shooter_barrel_heat_limit;
    TxNuc_TJ.ammo_remaining      = judgement.data.projectile_allowance_t.projectile_allowance_17mm;

    // 裁判系统
    TxNuc_TJ.game_progress     = judgement.data.game_status_t.game_progress;
    TxNuc_TJ.stage_remain_time = judgement.data.game_status_t.stage_remain_time;
    TxNuc_TJ.robot_hp          = judgement.data.robot_status_t.current_HP;
    TxNuc_TJ.ally_outpost_hp   = judgement.data.game_robot_HP_t.ally_outpost_HP;
    TxNuc_TJ.posture_current      = rc.AUTOmode;
    TxNuc_TJ.posture_cd_remain_ms = rc.posture_cd_remain_ms;
    TxNuc_TJ.crc16_TJ             = 0;  // CRC未启用，固定发0

    // 发送（直接从结构体发送，无需中间缓冲区）
    m_uart->UARTTransmit(reinterpret_cast<uint8_t*>(&TxNuc_TJ), sizeof(TxNuc_TJ));

}
struct TxPacket_TJ
{
    uint8_t head[2] = { 'S', 'P' };
    uint8_t mode_TJ;  // 0: 空闲, 1: 自瞄, 2: 小符, 3: 大符
    float yaw_TJ;
    float yaw_vel_TJ;
    float pitch_TJ;
    float pitch_vel_TJ;
    float roll_TJ;
    float roll_vel_TJ;
    float bullet_speed_TJ;
    uint16_t bullet_count_TJ;  // 子弹累计发送次数
    int8_t game_status_NAV;    // 0:未开始 1:开始 2:结束
    // 底盘
    float chassis_vx;
    float chassis_vy;
    float chassis_wz;
    // 资源约束
    float chassis_power_limit;
    float buffer_energy;
    float shooter_heat;
    float shooter_heat_limit;
    int32_t ammo_remaining;
    // 裁判系统
    int32_t game_progress;
    int32_t stage_remain_time;
    int32_t robot_hp;
    int32_t ally_outpost_hp;
    int8_t posture_current;
    int32_t posture_cd_remain_ms;
    uint16_t crc16_TJ;

}__attribute__((packed));
