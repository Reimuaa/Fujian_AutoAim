# 本机运行资源

本目录仍作为本机运行资源目录忽略，只跟踪这份说明。2026-10-17用户授权的模型快照分类保存于[models/](../models/README.md)，并登记来源和SHA-256；图片、视频和SDK不在该快照中。
当前正式配置使用 `yolo26.xml`、`yolo26.bin`，分类器资源为 `tiny_resnet.onnx`。
资源路径、体积及 SHA-256 见 `docs/artifacts.json`。现有小电脑资源仍在原路径，未从磁盘删除。
新克隆可从用户授权的 `field-2026.10.11` Release 恢复资源，方法见 [快速恢复](../docs/recovery.md)及[依赖说明](../docs/dependencies.md)。
