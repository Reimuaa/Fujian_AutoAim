## 目录

| 目录 | 用途 |
|---|---|
| `src/` | 程序入口，正式程序为 `standard` |
| `tasks/auto_aim/` | 识别、目标跟踪、预测及调度 |
| `io/` | 相机、串口及设备接口 |
| `tools/` | 公共算法、一键启动与停止脚本 |
| `calibration/` | 标定与验证工具源码 |
| `configs/standard.yaml` | 唯一正式运行配置 |
| `configs/calibration.yaml` | 标定工具配置，不能当作正式运行配置 |
| `tests/` | 离线及接口测试源码 |
| `assets/`、`librm/` | 本机模型位置（不入库）与源码依赖子模块 |
| `firmware/` | 步兵和哨兵两个硬件目标的当前固件 |
| `simulation/` | 格式塔仿真成果 |
| `docs/` | 当前使用与维护文档 |

`build/`、`logs/`、`data/` 为本机生成内容，不提交 Git。
桌面“启动自瞄”“停止自瞄”仍为现场入口，红蓝选择继续持久化，运行日志保留最近20份。

## 当前工作状态

截至2026-10-11晚间，用户反馈当前版本准确率很高，并要求发布保留。旋转水平门限为0.5°，Aimer高、低速基础预测延迟均为325ms，配置弹速20m/s，P轴弹道微调-0.50°；ROI和角点细化开启，详细诊断关闭。高速事件调度的独立发射延迟仍为85ms。参数试验没有改变C++预测算法。日志没有完整的实际出弹/命中标签，因此不虚构命中率百分比。

小电脑现场源码、Windows仿真支持和开发/烧录说明均随源码维护，目标分支已有哨兵与标定资料继续保留。步兵与哨兵固件分别保留，仓库源码不代表车上已烧录版本。恢复到Ubuntu 22.04 x86_64时，按[恢复说明](docs/recovery.md)克隆发布标签并运行校验/安装工具，可恢复现场程序和资源；该工具不会启动自瞄或烧录固件。
