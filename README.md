# RoboMaster 视觉与控制工程

最终版本标记为`26.10.25final`，采用用户确认未再改动的小电脑源码与正式配置。保留原静止/低速/高速自动分类，不包含本机未部署的“固定高速比赛模式及失信1秒重建”试验补丁。当前运行源码按工作区约定与最后一次小电脑只读清单逐文件核对，发布说明另行补充；小电脑未被修改。

保留静止、低速、高速三态分类。静止/低速使用独立旧Tracker的ESKF/CV及原有vehicle选择；高速使用整车预测，并在固定中心联合模型持续就绪200ms、至少3帧后由其接管预测和中心跟随。高速逐面保持身份完成迭代，在最终预测点检查原可射角并要求收敛；两种预测各自维护分面修正和历史质量，切换清空资格。高速非PLL历史质量门开启时，必须完成同面、相近转角的至少3次独立过面验证，历史未就绪时暂停新请求并继续跟踪、学习。见[修正与配置说明](docs/configuration.md)。

正式配置仅为`configs/standard.yaml`。当前高速基础补偿按俯视旋向独立设置：顺时针385ms、逆时针325ms，公共回退365ms；静止330ms、低速320ms。shoot=1为单包请求，shoot=0最短释放高速1000ms、静止/低速50ms，额外最小请求间隔均为0ms。PLL关闭；本次发布配置沿用小电脑的完整诊断关闭状态。后续代码改进默认只作用于高速；开火后的延迟和弹速由用户调试。桌面日志切换兼容LF/CRLF配置，切换后需用户重启原入口。现场程序由用户自行启停，离线视觉误差不代表实弹命中率。

高速历史质量门在短暂缺少预测时保留最近查询不足150ms，并继续检查历史误差；独立的当前预测/观测资格阻止缺口中的新请求。高速批量重投影保持原140个1°候选及选优规则。小电脑已部署历史质量修复、批量重投影及固定两帧资格；近期生产源码已与本机核对一致，具体同步和验证范围见[当前状态](docs/status.md)。

本仓库保存当前维护的一份源码。小电脑正式目录：`/home/rm/sp_vision`。

靶车灯灭返航已同步小电脑：有效`mode=1`且3帧确认过亮灯靶车后，连续1500ms新鲜全画面无敌方目标才请求`control_TJ=2、shoot_TJ=0`；去程或到位后从未见到靶车不会触发。返航事件单进程只产生一次，发送器持续保持返航指令。小电脑standard编译及9项离线回归通过，由用户重启原入口后生效，流程及参数见[配置说明](docs/configuration.md#靶车灯灭返航已同步)。

| 目录 | 用途 |
|---|---|
| `src/` | 程序入口，正式程序为 `standard` |
